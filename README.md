# MOV Updates

Public distribution for **MOV Personal Cinema**.

This repository contains only app release packages and update metadata. Source code stays in the private `MOV-Cinema` repository. Personal movies, TV shows and library data must never be uploaded here.

**Release downloads:** [GitHub Releases](../../releases)

The updater is being configured. Until a signed macOS app and a published release exist, automatic installation on Mac is **not enabled**. Windows auto-updates require an installable NSIS build rather than the earlier portable EXE. Do not treat unsigned test builds as production releases.
